# How to Evaluate Open Models for Your Coding Agents

[**Open the live interactive tutorial**](https://az9713.github.io/open-model-evaluation-baseten/)

A dark-mode visual tutorial based on Baseten’s webinar on evaluating open models for coding agents. It explains how to define representative tasks, compare complete agent systems fairly, verify fixes and regressions, and measure cost and time per accepted task.

The tutorial includes an executive summary, interactive cost and latency examples, workflow diagrams, formatted equations, and three short understanding checks. The HTML runs locally without a build step or external runtime dependencies.

## Source video

[**How to Evaluate Open Models for Your Coding Agents — Baseten**](https://www.youtube.com/watch?v=2ytlRcUzgpM), featuring Alex Ker and Molly Elfers, published October 28, 2026.

Additional reference: [Baseten’s guide to evaluating open-source models for coding use cases](https://www.baseten.co/articles/how-to-evaluate-open-source-models-for-coding-use-cases/).

The tutorial follows the video’s verified chapter framework and companion guidance. The complete spoken transcript was unavailable; it does not claim to reproduce every example or Q&A answer. Illustrative calculations, diagrams, and animations are labeled teaching additions, not measured benchmark results. This is an independent learning resource, not an official Baseten publication.
